    How this site is built

    Hand-written HTML, CSS and TypeScript, with Rust compiled to WebAssembly. No framework and no trackers.

    Languages
    TypeScript for the page logic, type-checked on every push. Rust compiled to WebAssembly for the three demo engines: the order book, the Black-Scholes pricer and the HNSW search. Python for the build, the browser tests and the charts. HTML and CSS for everything you see.
    Weight
    42 KB of page and 9 KB of WebAssembly, gzipped, before images. The build measures both on every change.
    Routing
    Every page, case study and post lives in one document and is chosen by the URL hash, so links to any page work and the back button behaves. Page changes use the View Transitions API where the browser has it, and skip it for anyone who prefers reduced motion.
    Command line
    Modelled on Kestrel, my terminal. ⌘K or / opens it; commands match by code, then by prefix, then by subsequence. It is an ARIA listbox, so it works from the keyboard and with a screen reader. Type ? to list every command.
    Demos
    The order book, the pricer and the HNSW search run in Rust compiled to WebAssembly, on the home page and on each project page, with Rust unit tests for the matching order, the option values and the search result. Each keeps a TypeScript version as a fallback for browsers without WebAssembly. The live order book streams Coinbase’s public feed.
    Privacy
    No cookies, no analytics and no third-party requests: the code, fonts and images are all served from this site. Only the Kestrel page connects elsewhere, to Coinbase’s public market data, for its live order book. Local storage holds only your theme.
    Type and color
    Instrument Sans and IBM Plex Mono, both under the SIL Open Font License and served from this site. Warm paper and deep teal, in light and dark.
