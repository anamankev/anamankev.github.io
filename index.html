How this site is built

One hand-written file of HTML, CSS and JavaScript. No framework, no bundler, no trackers.

Weight
29 KB gzipped before images, measured by the build script on every change. A shell script wraps the page and writes this number in.
Routing
Every page, case study and post lives in one document and is chosen by the URL hash, so links to any page work and the back button behaves. Page changes use the View Transitions API where the browser has it, and skip it for anyone who prefers reduced motion.
Command line
Modelled on Kestrel, my terminal. ⌘K or / opens it; commands match by code, then by prefix, then by subsequence. It is an ARIA listbox, so it works from the keyboard and with a screen reader. A few commands are hidden: try HELP.
Demos
The order book uses Brier’s matching rule (best price, then oldest order). The HNSW search runs on the actual graph hnsw-engine built. The pricer uses the same Black-Scholes-Merton formulas as my options library. All three run in your browser with no server.
Live data
The “latest commit” line on the home page calls the public GitHub API, caches the answer for ten minutes in session storage, and disappears quietly if GitHub doesn’t answer.
Résumé
A print stylesheet turns the same data into a one-column résumé. Use the résumé button or the CV command, then print or save as PDF.
Privacy
No cookies and no analytics. Local storage holds only your theme and which secrets you’ve found. Fonts load from Google Fonts.
Type and color
Plus Jakarta Sans and IBM Plex Mono. Graphite and cyan, the same palette as Kestrel, in light and dark.
